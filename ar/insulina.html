آلة حاسبة سريعة وآمنة لسحب الوحدات الدولية (UI).

الأدوية التقطير مؤشر كتلة الجسم عمر الحمل وتاريخ الولادة المتوقع الأهداف الدولية

آلة حاسبة الأنسولين

تأكد من توفر تركيز قبل الحساب.

التركيز مستقل عن حجم المحقنة. إذا لم يكن المستحضر U-100، لا تستخدم هذه النسخة من الآلة الحاسبة.

حجم المحقنة لا يغير تركيز الأنسولين.

الرجاء إدخال جرعة صالحة بوحدة UI.

القياسات والنسب الأساسية

أمثلة رياضية لـ U-100 (100 UI/mL):

  • 100 UI تعادل 1.0 mL
  • 50 UI تعادل 0.5 mL
  • 30 UI تعادل 0.3 mL
  • 10 UI تعادل 0.1 mL

نصيحة السلامة: استخدم المحقنة المتوافقة مع المستحضر والتدريج المحدد في البروتوكول المعمول به. اختيار حجم المحقنة لا يغير تركيز المنتج.

الحجم للسحب

النتيجة الرياضية بالملليلتر (mL)؛ تحقق من التدريج والبروتوكول المعمول به قبل أي استخدام.

التحقق الفعلي والتفصيل

التحقق المزدوج بروتوكول السلامة الإلزامي تنبيه: دواء عالي اليقظة الأهداف الدولية لسلامة المريض ✓ الهدف 1 ✓ الهدف 2 ✓ الهدف 3 ✓ الهدف 5
