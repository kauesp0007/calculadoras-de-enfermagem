Inteligência decisória

Decision Support
When To Use
  • ConditionIM adulto (glúteo, vasto lateral)
    Recommendation21G x 25mm ou 22G x 25mm
  • ConditionSC adulto (abdômen, braço)
    Recommendation25G x 16mm ou 27G x 13mm
  • ConditionID (teste de hipersensibilidade)
    Recommendation27G x 13mm ou 29G x 13mm
  • ConditionPunção venosa para infusão
    Recommendation20G x 32mm (adulto) ou 22G x 25mm (veias delicadas)
  • ConditionColeta de sangue
    Recommendation21G ou 22G x 32mm
When To Avoid
  • Agulha grossa para via subcutânea (causa dor e lesão)
  • Agulha fina para IM (pode obstruir)
Decision Matrix
  • Clinical ScenarioPaciente adulto para aplicação IM no ventroglúteo
    Recommended Device21G x 25mm
    ReasonCalibre e comprimento adequados para músculo profundo
    Evidence LevelAlta
  • Clinical ScenarioPaciente idoso com veias frágeis
    Recommended Device23G ou 25G x 20mm
    ReasonCalibre menor para minimizar trauma
    Evidence LevelModerada
