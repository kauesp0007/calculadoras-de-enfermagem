血管外科学会 WIfI 分类

1. 引言

WIfI 分类（伤口、缺血、足部感染）是由美国血管外科学会（SVS）开发的风险分层系统，用于评估外周动脉疾病和糖尿病足患者的濒临截肢的下肢。该分类最初于2014年在《血管外科杂志》上发表（MILLS 等，2014），由 SVS 的下肢指南委员会制定，旨在统一各医学专业——血管外科医生、内分泌科医生、感染科医生、骨科医生和护士——之间的语言，并允许在不同中心和研究之间对临床结果进行客观比较（MILLS 等，2014，第 221 页）。

与以往仅关注疾病单一方面的分类系统（如 Fontaine 分类（缺血）、Wagner 分类（伤口）或 IDSA 分类（感染））不同，WIfI 系统整合了三个独立轴，综合确定一年内大截肢的总体风险和血运重建的获益可能性（MILLS 等，2014）。Mills 等（2014，第 222 页）指出“WIfI 分类旨在基于三个关键因素对截肢风险进行分层：伤口、缺血和足部感染，每个因素按 0 至 3 的等级进行分级”。

2. 历史与作者

年份事件
2013由 Dr. Joseph L. Mills Sr. 担任主席的 SVS 下肢指南委员会开始制定综合分类系统。该委员会汇集了来自美国和欧洲不同机构的 14 位专家（MILLS 等，2014）。
2014年1月在《血管外科杂志》（第 59 卷，第 1 期，第 220-234.e2 页）上正式发表，标题为“血管外科学会下肢濒危肢体分类系统：基于伤口、缺血和足部感染（WIfI）的风险分层”（MILLS 等，2014）。
2014-2019在美国、欧洲和亚洲的多个中心进行临床验证。研究表明 WIfI 临床分期是 1 年内大截肢和死亡率的独立预测因子（ZETTERVALL 等，2015；DARLING 等，2016）。
2019《全球血管指南》（CONTE 等，2019）认可 WIfI 分类作为慢性威胁肢体缺血（CLTI）风险分层的国际标准。
2020年至今在巴西逐步采用，获巴西血管学和血管外科学会（SBACV）推荐，并被纳入巴西大学医院的糖尿病足管理方案（SBACV，2020）。

起源地区和参与机构

该分类在美国开发，由亚利桑那大学（图森，亚利桑那州）牵头，涉及哈佛医学院（波士顿，马萨诸塞州）、加利福尼亚大学（旧金山，加利福尼亚州）和梅奥诊所（罗切斯特，明尼苏达州）等中心。专家小组包括血管外科医生、内分泌科医生、感染科医生和伤口专家（MILLS 等，2014）。

使用该分类的国家

国家/地区使用背景
美国起源和初步验证；SVS 血运重建临床试验标准（MILLS 等，2014）
欧盟获《全球血管指南》认可（CONTE 等，2019）；用于德国、英国、意大利和荷兰的多中心注册研究
日本和亚洲在亚洲糖尿病足人群中验证；针对解剖学和流行病学差异进行了调整（AZUMA 等，2018）
巴西获 SBACV 推荐；用于大学医院（USP、UNICAMP、UFRJ）和糖尿病足参考服务中心（SBACV，2020）

3. WIfI 分类的三个组成部分

该分类评估三个独立参数，每个参数按0 至 3 分级，其中 0 = 正常/无，3 = 严重损害。W、I 和 fI 等级的组合确定WIfI 临床分期（1 至 4），进而估计 1 年内截肢风险和预期的血运重建获益（MILLS 等，2014，第 223 页）。

组成部分等级描述
W — 伤口0无溃疡，无坏疽（可能存在缺血性静息痛）
1小腿远端或足部的小而浅表溃疡；无骨暴露，除非仅限于远端趾骨；无坏疽或坏疽仅限于远端趾骨
2深部溃疡，伴有骨、关节或肌腱暴露；通常不涉及足跟；坏疽仅限于足趾
3广泛深部溃疡，累及前足和/或中足；跟骨深部溃疡（±跟骨）；广泛坏疽累及前足和/或中足；跟骨广泛坏死
I — 缺血0ABI ≥ 0.80；踝部收缩压 > 100 mmHg；拇趾压力（TP）或 TcPO₂ ≥ 60 mmHg
1ABI 0.60-0.79；踝部收缩压 70-100 mmHg；TP/TcPO₂ 40-59 mmHg
2ABI 0.40-0.59；踝部收缩压 50-70 mmHg；TP/TcPO₂ 30-39 mmHg
3ABI ≤ 0.39；踝部收缩压 < 50 mmHg；TP/TcPO₂ < 30 mmHg
fI — 足部感染0无感染体征或症状；无活动性感染证据
1仅涉及皮肤和皮下组织的局部感染（无深部组织受累，无全身体征）；溃疡周围红斑 > 0.5 cm 且 ≤ 2 cm
2局部感染，红斑 > 2 cm，或累及深部结构（脓肿、骨髓炎、化脓性关节炎、筋膜炎）；无 SIRS（全身炎症反应综合征）
3局部感染伴 SIRS 体征（≥ 2 项标准：体温 > 38°C 或 < 36°C；心率 > 90 次/分；呼吸频率 > 20 次/分或 PaCO₂ < 32 mmHg；白细胞 > 12,000 或 < 4,000/µL 或 > 10% 杆状核）

来源：改编自 MILLS 等（2014，第 223-225 页）。ABI = 踝臂指数；SBP = 收缩压；TP = 拇趾压力；TcPO₂ = 经皮氧分压；SIRS = 全身炎症反应综合征。

注意： WIfI 分类应由受过培训的专业人员应用。评分的解读和临床处理方案的确定——尤其是血运重建和截肢的指征——属于血管科医生的职责范围（MILLS 等，2014；SBACV，2020）。

7. 治疗和临床措施

对威胁肢体的管理需要多学科的干预，包括血管外科、内分泌学、感染学、骨科和专门的伤口护理。Mills 等人（2014，p. 230）强调“WIfI 分类并不是为了决定治疗，而是为了提供一个框架，以便在不同治疗方式之间进行有意义的结果比较”。

根据 WIfI 阶段的措施

阶段再血管化伤口感染
1很少需要局部护理 + 适当的敷料如果存在感染则口服抗生素
2通过多普勒/血管造影评估清创 + 先进敷料针对性抗生素 + 引流
3可能需要；转诊至血管外科广泛清创 + 负压治疗广谱静脉抗生素 + 手术
4为拯救肢体而需要（旁路/血管成形术）评估小/大截肢静脉抗生素 + 紧急手术

下肢血管成形术检查

评估动脉灌注在 WIfI 分类中是强制性的。补充检查包括（MILLS 等人，2014；CONTE 等人，2019）：

  • ITB（踝臂指数）： 一线检查，非侵入性。值 < 0.90 表示外周动脉疾病； < 0.40 表示危急缺血。
  • 大拇趾压力（TP）： 在糖尿病患者中更可靠（胫骨动脉钙化可能会影响 ITB）。TP < 30 mmHg 表示危急缺血。
  • TcPO₂（经皮氧气压力）： 预测伤口愈合。TcPO₂ < 30 mmHg 表示在没有再血管化的情况下愈合的可能性低。
  • 动脉超声多普勒： 映射血管解剖并识别狭窄/闭塞。
  • 血管造影（通过导管或血管 CT/血管 MRI）： 再血管化手术规划的金标准。

糖尿病足的护理措施

护士在评估和护理 WIfI 分类的糖尿病足患者中发挥着核心作用（SBACV，2020；国际糖尿病足工作组 [IWGDF]，2019）：

  • 系统评估足部： 每日检查，触诊足背和后胫动脉脉搏，使用 10g 单丝（Semmes-Weinstein）和 128 Hz 音叉进行感觉测试。
  • 分类和记录： 应用 WIfI 分类并拍照记录伤口的演变。
  • 专业敷料： 根据渗出程度、深度和感染情况选择敷料 — 水胶体、海藻酸盐、水纤维、泡沫、含银活性炭。
  • 负压治疗（TPN）： 适用于大量渗出（W2-W3）的广泛伤口。
  • 压力卸载： 使用治疗鞋、全接触石膏（TCC）或矫形器重新分配足底压力。
  • 患者和家属教育： 关于足部自我护理、血糖控制、戒烟和早期识别警示信号的指导。
  • 再血管化后的监测： 评估远端灌注、肢体温度、颜色和毛细血管充盈。

8. 预后

WIfI 分类的糖尿病足患者的预后取决于三个主要因素：代谢控制（HbA1c < 7%），成功的再血管化（如有必要）和 感染控制（IWGDF，2019）。验证研究表明（ZETTERVALL 等人，2015；DARLING 等人，2016）：

  • WIfI 阶段 1-2 的患者在适当的临床管理下，1 年的肢体保存率超过 95%。
  • WIfI 阶段 3 的患者在再血管化的情况下，1 年的截肢率约为 10-15%。
  • WIfI 阶段 4 的患者在 1 年内的截肢率超过 30%，死亡率为 20-25%，通常由于心血管事件。
  • 重度感染的存在（fI3）是立即大截肢的最强单一预测因子。
有利预后： WIfI 1-2，良好的血糖控制（HbA1c < 7%），及时的再血管化和无重度感染。肢体保存率：> 90%。

9. 预防：糖尿病控制、饮食、久坐和吸烟

预防糖尿病足和进展到 WIfI 的高级阶段基于四个可改变的支柱（IWGDF，2019；巴西糖尿病协会 [SBD]，2023）：

9.1 严格的血糖控制

  • HbA1c 目标： 成人 < 7.0%；对老年人和多重合并症患者个体化（SBD，2023）。
  • 监测： 餐前血糖（80-130 mg/dL）和餐后血糖（< 180 mg/dL）。
  • 药物依从性： 口服降糖药（美克洛尔、SGLT2 抑制剂、GLP-1 激动剂）和胰岛素治疗根据处方。
  • UKPDS（1998）研究表明，HbA1c 降低 1% 可使微血管并发症减少 37%，包括神经病和足部溃疡。

9.2 适当的饮食

  • 均衡饮食，45-60% 低血糖指数碳水化合物，15-20% 蛋白质 和 20-35% 不饱和脂肪（SBD，2023）。
  • 限制简单碳水化合物（糖、白面粉、汽水）和饱和/反式脂肪。
  • 摄入纤维（≥ 25 g/天）、水果、蔬菜和全谷物。
  • 将餐食分为 5-6 次，以避免血糖峰值。

9.3 抵制久坐

  • 每周至少150 分钟中等强度有氧运动（步行、游泳、骑自行车）或75 分钟高强度运动（世界卫生组织，2020）。
  • 每周进行 2-3 次肌肉强化锻炼。
  • 定期锻炼可改善胰岛素敏感性，降低 HbA1c 0.6-0.8%，改善外周循环 — 这是对缺血的保护因素（IWGDF，2019）。
  • 重要： 神经病患者应避免高冲击运动和赤脚行走，以防止足部受伤。

9.4 戒烟

  • 吸烟是可改变的主要风险因素，导致外周动脉疾病和 WIfI 中缺血的进展（MILLS 等人，2014）。
  • 吸烟者的危机增加 2-4 倍，与非吸烟者相比，发展为危急缺血和大截肢的风险。
  • 戒烟可在 5 年内将截肢风险降低 50%（IWGDF，2019）。
  • 策略：尼古丁替代疗法（贴片、口香糖）、布普洛尼、伐尼克兰和心理支持。

10. 摘要

WIfI 分类由血管外科协会的下肢指南委员会开发，并由 Mills 等人（2014）在血管外科杂志上发表，是对威胁下肢截肢风险的国际标准分层。由三个参数组成 — 伤口（Wound）、缺血（Ischemia）和足部感染（foot Infection） — 每个参数从 0 到 3 进行分级，该分类允许估计 1 年内大截肢的风险（表 IV）和预期的再血管化收益（表 V），前提是感染得到控制。临床措施应由血管外科医生根据 WIfI 阶段（1 到 4）确定，并需要多学科的干预，包括护理、内分泌学、感染学和骨科。预防基于严格的血糖控制、均衡饮食、定期锻炼和戒烟。其实际应用可在本网站的在线计算器中获得（MILLS 等人，2014；CONTE 等人，2019；IWGDF，2019；SBACV，2020）。
