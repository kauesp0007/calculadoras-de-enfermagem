重症监护评分量表简介

A 重症监护病房（ICU） 是医院中集中收治最危重患者的环境，这些患者有迫在眉睫的死亡风险，需要持续监测和复杂干预。在这种情况下， 评估量表 是量化严重程度、预测结果、指导治疗决策和优化资源分配不可或缺的工具。

与其他专科通常只关注单一器官系统的量表不同，ICU量表往往是多系统的，反映了危重患者可能同时出现多器官功能障碍的复杂性质。 多系统，反映了危重患者可能同时出现多器官功能障碍的复杂性质。

O APACHE II （急性生理与慢性健康评估）是世界上最知名的严重程度评分。在入院后24小时内应用，使用12个生理变量、年龄和合并症来估计住院死亡风险。而 SOFA （序贯器官衰竭评估）每日评估六个器官系统的功能障碍，目前是脓毒症定义的主要标准，根据Sepsis-3共识：SOFA增加2分或更多，加上感染，定义脓毒性状态。

除了严重程度评分外，重症监护护士还使用量表来 谵妄检测 （CAM-ICU）， 神经学评估 在镇静或插管患者中（FOUR、格拉斯哥）， 非语言患者的疼痛评估 （BPS——行为疼痛量表）和 呼吸道感染的严重程度分层 （CURB-65）。

系统化应用这些量表，并结合护理系统化（SAE），可以早期发现临床恶化，在多学科查房时进行准确沟通，并客观评估治疗干预的效果。

常见问题

什么是SOFA评分以及如何解读？
SOFA（序贯器官衰竭评估）评估6个器官系统的功能障碍：呼吸系统（PaO₂/FiO₂）、凝血系统（血小板）、肝脏系统（胆红素）、心血管系统（MAP和血管加压药的使用）、神经系统（格拉斯哥昏迷评分）和肾脏系统（肌酐或尿量）。每个系统评分0至4分，总分0至24分。与基线相比增加2分或以上，并伴有感染疑似，根据Sepsis-3定义脓毒症。评分越高，死亡率越高——研究表明SOFA≥11与超过80%的死亡率相关。
APACHE II和SOFA有什么区别？
APACHE II在入住ICU后24小时内仅应用一次，使用12项生理变量的最差值、年龄和慢性疾病的存在来预测住院死亡率。这是入院时严重程度的“快照”。而SOFA每天计算，允许随时间跟踪器官功能障碍的进展——这是危重患者的“电影”。此外，SOFA是脓毒症的定义标准（Sepsis-3），而APACHE II主要是预后评分。在实践中，两者互补：APACHE II估计基线风险，SOFA监测对治疗的反应。
如何在机械通气患者中应用CAM-ICU？
CAM-ICU适用于机械通气患者。首先，评估RASS（里士满激动-镇静量表）。如果RASS = -4或-5（深度昏迷），停止——患者不适合。如果RASS ≥ -3，继续：（1）精神状态的急性改变或波动——与基线比较；（2）注意力不集中——字母测试（在听到序列S-A-V-E-A-H-A-A-R-T中的“A”时握手）或图片测试；（3）思维紊乱——提出4个简单问题并要求举起2根手指；（4）意识水平改变——RASS不同于0。当特征1 + 2 +（3或4）存在时，诊断为谵妄。评估应在每个班次进行。
