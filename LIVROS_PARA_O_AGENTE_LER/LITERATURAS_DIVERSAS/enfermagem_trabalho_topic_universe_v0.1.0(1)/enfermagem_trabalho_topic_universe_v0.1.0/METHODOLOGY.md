# Metodologia — Topic Universe

## Fluxo

Matriz T/G/P → mapa de cobertura → taxonomia → tópicos candidatos → atomização → claims → fontes → relações → intenções editoriais → páginas → renderização.

## Níveis

- **T**: reconhecer, executar dentro da competência, registrar, comunicar e encaminhar;
- **G**: analisar, planejar, integrar cuidado e interpretar dados;
- **P**: integrar sistemas, auditar, governar, desenhar programas e avaliar resultados.

## Regras de evidência

1. Jurisdição não é inferida pelo idioma.
2. Norma brasileira e evidência científica global são camadas separadas.
3. `topic_inventory` não equivale a `atomic_knowledge`.
4. Átomo precisa de statement + source id.
5. Conteúdo final precisa de claims específicos e não apenas de uma bibliografia genérica.
6. Fonte temporal/dinâmica recebe data de verificação.
7. Não promover conteúdo regulatório sem checar vigência.

## Regra de duplicidade

Bloquear duas páginas quando intenção, outline e conjunto de tópicos forem excessivamente semelhantes. Reusar átomos; não clonar parágrafos.
