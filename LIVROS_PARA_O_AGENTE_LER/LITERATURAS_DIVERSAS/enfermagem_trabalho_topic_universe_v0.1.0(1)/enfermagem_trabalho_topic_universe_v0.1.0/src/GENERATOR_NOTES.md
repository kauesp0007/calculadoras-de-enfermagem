Gerar páginas sempre a partir de: fontes registradas + atoms promovidos + manifesto + relações.
Não usar idioma como proxy de jurisdição.
Bloquear páginas com intenção/outline excessivamente duplicados.
Não confundir tópico candidato com claim validado.
Para normas e eSocial, checar a versão vigente no momento do build.
Para PPRA, manter lifecycle histórico/legado e direcionar conteúdo vigente a GRO/PGR.
Para limites profissionais, não extrapolar escopo de Técnico, Enfermeiro ou outros profissionais legalmente responsáveis.
