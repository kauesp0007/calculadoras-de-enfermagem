ECONOMIA DE CREDITOS DE IA E IMPACTO ECONOMICO
Projeto: Calculadoras de Enfermagem
Natureza: estimativas qualitativas e framework de calculo (valores ilustrativos).

IDEIA CENTRAL
A arquitetura (8 agentes + 5 hooks) foi desenhada para GASTAR MENOS creditos, nao mais.
Tudo que pode ser automatizado de forma deterministica vira hook (custo ~0).
Tudo que exige julgamento vira agente especializado e enxuto (custo pequeno e contido).

COMO A ECONOMIA ACONTECE (5 MECANISMOS)
1. Hooks nao usam IA - auto-backup, build-after-edit, content-governance,
   knowledge-index e security-git rodam em PowerShell local. Zero tokens de modelo.
2. Subagentes encapsulam contexto - o agente filho le arquivos grandes e devolve
   apenas o relatorio final; as buscas intermediarias nao poluem a conversa principal.
3. Prompts pequenos e especializados - cada .agent.md tem dezenas de linhas; o agente
   nao recarrega AI_RULES.md e catalogos desnecessariamente.
4. tools restritos - auditores tem so read/search; Build so execute. Menos ferramentas
   = menos esquema = menos tokens e menos risco de acao errada.
5. Menos erros, menos retries - hooks garantem backup/build/validacao sem depender da
   memoria do modelo; menos esquecimento = menos correcoes = menos chamadas repetidas.

FRAMEWORK DE CUSTO (ILUSTRATIVO)
Backup antes de editar: sem arquitetura = chamada + leitura do modelo; com = hook local (0 tokens)
Build pos-edicao (SW + Tailwind): sem = 2+ chamadas manuais; com = hook local (0 tokens)
Validacao de governanca: sem = auditoria via modelo; com = hook local + Node (0 tokens)
Reindexacao do conhecimento: sem = modelo lendo /knowledge/; com = hook local + Node (0 tokens)
Bloqueio de commit/push: sem = depende da memoria; com = hook local (0 tokens)
Pesquisa de conteudo: sem = modelo varre /knowledge/; com = agente Descoberta devolve dossie
Auditoria de SEO: sem = modelo le pagina + regras; com = agente Auditor SEO devolve relatorio

IMPACTO ECONOMICO (QUALITATIVO)
Custo de tokens: reduzido (hooks eliminam passos repetitivos; subagentes encapsulam).
Tempo de desenvolvimento: reduzido (passos automaticos nao esperam o modelo).
Consistencia: aumentada (hooks nao esquecem, nao variam, nao alucinam).
Risco operacional: reduzido (security-git impede commit/push; auto-backup protege dados).
Escalabilidade: cada pagina nova herda o pipeline sem custo incremental de raciocinio.

RESSALVA
Valores monetarios dependem do preco por token do modelo em uso (varia). Este documento
fornece o FRAMEWORK e a LOGICA de economia, nao uma cotacao. Para numero exato:
multiplicar tokens economizados pelo preco vigente do modelo.

ONDE AINDA SE GASTA (E E ACEITAVEL)
- Agentes de criacao/editaveis (Nova Calculadora, Gerador de Imagens, Tradutor):
  exigem IA (julgamento e escrita).
- Agentes de auditoria (Auditor SEO, Auditor de Governanca): evitam publicar errado.
- Descoberta de Conhecimento: evita duplicacao e correcoes posteriores.

CONCLUSAO
Economia nao vem de "nao usar IA", mas de usar IA apenas onde ha julgamento e
automatizar tudo que e deterministico. Hooks = camada de custo zero; agentes = camada
de julgamento contido.
