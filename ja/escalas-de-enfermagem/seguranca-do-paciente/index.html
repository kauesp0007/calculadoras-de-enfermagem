患者安全入門

これらは 院内転倒 は、入院部門における患者安全に関連する最も一般的な有害事象であり、発生率は患者1,000人日あたり1.3～8.9件です。約30%が傷害を引き起こし、5%が骨折や硬膜下血腫などの重篤な傷害を引き起こします。 世界保健機関（WHO）では、 国際合同委員会 と 国家患者安全プログラム（PNSP/保健省） は、転倒予防を国際安全目標の6つのうちの1つとして定めています。

予防の第一段階は リスクの特定。 モーススケール （Morse Fall Scale、1989年）は、入院成人患者の転倒リスク評価のゴールドスタンダードです。6項目、スコア0～125で、リスクを低（0-24）、中（25-45）、高（>45）に分類します。一方、 ダウントンスケール （1993年）は、老年医学および長期療養の場でより多く使用されています。

転倒リスクスケールと他の評価（例： Braden （褥瘡）、 Barthel （機能）、および GDS （高齢者のうつ病）— 患者安全への多次元的アプローチを可能にします。

スケールと計算ツール

Morse

院内転倒リスク

病院のゴールドスタンダード。6項目。スコア0-125。> 45 = 高リスク。全成人患者の入院時に必須。

Morseを開く

Downton

高齢者の転倒リスク

老年医学における転倒評価。5項目。スコア0-11。≥ 3 = リスク。簡便で迅速。

Downtonを開く

Braden

褥瘡リスク

皮膚の安全を全体の安全に統合。褥瘡患者は可動性が低下し、転倒リスクが高い。

Bradenを開く

Barthel

機能的独立性

ADLを評価。Barthelの低スコアは転倒リスクと依存度の増加と相関。

Barthelを開く

よくある質問

モースとダウントンの違いは何ですか？
モース（6項目、0-125）：転倒歴（25点）、二次診断（15点）、歩行補助（0-30点）、静脈アクセス/生理食塩水ロック（20点）、歩行（0-20点）、精神状態（15点）を評価。> 45 = 高リスク。急性期患者に対してより感度が高く、病院のゴールドスタンダードです。ダウントン（5項目、0-11）：転倒歴（1点）、薬剤（クラスごとに1点）、感覚障害（1点）、精神状態（1点）、歩行（1点）を評価。≥ 3 = リスク。より簡便で、老年医学/施設に適しています。
転倒予防プログラムをどのように実施しますか？
実施方法：(1) 入院時にモースで評価し、48時間ごとに再評価。(2) 視覚的識別（黄色いリストバンドとベッドのプレート）。(3) 普遍的な対策 — ベッドを低く固定、ベッド柵、照明、手の届く範囲のナースコール、滑りにくい床。(4) リスクに応じた具体的な対策 — モース > 45：付き添い、入浴の監督、理学療法。(5) 薬剤の見直し（ベンゾジアゼピン、降圧薬、利尿薬）。(6) すべての転倒の報告と根本原因分析。転倒率を品質指標として監視。
