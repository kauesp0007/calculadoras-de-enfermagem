集中治療スケールの紹介

A 集中治療室（ICU） は、最も重症で、差し迫った死亡リスクがあり、継続的なモニタリングと複雑な介入を必要とする患者が集中する病院環境です。この文脈では、 評価スケール は、重症度を定量化し、転帰を予測し、治療方針を導き、リソースの割り当てを最適化するための不可欠なツールです。

他の専門分野で使用されるスケール（通常は単一の臓器系に焦点を当てる）とは異なり、ICUスケールはしばしば 多系統的であり、複数の臓器に同時に機能不全を呈する可能性がある重症患者の複雑な性質を反映しています。

O APACHE II （急性生理学および慢性健康評価）は、世界的に最もよく知られている重症度スコアです。入院後最初の24時間に適用され、12の生理学的変数、年齢、併存疾患を使用して院内死亡リスクを推定します。一方、 SOFA （逐次臓器不全評価）は、6つの臓器系の機能不全を毎日評価し、現在ではSepsis-3コンセンサスによる敗血症定義の主要基準となっています：SOFAの2ポイント以上の増加が感染と関連する場合、敗血症性状態と定義されます。

重症度スコアに加えて、集中治療看護師は以下のためにスケールを使用します。 せん妄の検出 （CAM-ICU）、 鎮静または挿管患者の神経学的評価 （FOUR、グラスゴー）、 非言語患者の疼痛評価 （BPS — 行動疼痛スケール）、および 呼吸器感染症の重症度層別化 （CURB-65）。

これらのスケールを看護ケアの体系化（SAE）に統合して体系的に適用することで、臨床的悪化の早期発見、多職種ラウンド中の正確なコミュニケーション、治療介入への反応の客観的評価が可能になります。

スケールと計算ツール

APACHE II

急性生理学および慢性健康評価

ICUの重症度評価のゴールドスタンダード。12の生理学的変数、年齢、慢性疾患を使用します。院内死亡率を予測します。スコア0-71。

APACHE IIを開く

SOFA

逐次臓器不全評価

臓器不全（6システム）の毎日の評価。敗血症の定義基準（Δ ≥ 2）。治療反応をモニタリングします。スコア0-24。

SOFAを開く

CAM-ICU

Confusion Assessment Method for ICU

人工呼吸器装着中の重症患者のせん妄検出。4つの特徴：変動、不注意、思考の混乱、意識レベル。

CAM-ICUを開く

BPS

行動的疼痛スケール

人工呼吸器と鎮静下の患者の疼痛評価。表情、上肢、人工呼吸器への適応を分析します。スコア3-12。

BPSを開く

CURB-65

肺炎の重症度

市中肺炎の重症度を層別化します。5つの基準：混乱、尿素、呼吸、血圧、年齢≥65。スコア0-5。

CURB-65を開く

グラスゴー

グラスゴー昏睡尺度

ICUでの意識レベルの評価。挿管患者ではFOURを補完します。連続的な神経学的モニタリング。

グラスゴーを開く

よくある質問

SOFAスコアとは何か、どのように解釈するか？
SOFA（Sequential Organ Failure Assessment）は、呼吸器（PaO₂/FiO₂）、凝固（血小板）、肝臓（ビリルビン）、心血管（平均血圧と昇圧薬使用）、神経（グラスゴー）、腎臓（クレアチニンまたは尿量）の6つの臓器系の機能障害を評価します。各システムは0〜4点で評価され、合計は0〜24点です。ベースラインから2点以上の増加があり、感染が疑われる場合、Sepsis-3に基づき敗血症と定義されます。スコアが高いほど死亡率が高く、SOFA ≥ 11は80%を超える死亡率と関連することが研究で示されています。
APACHE IIとSOFAの違いは何ですか？
APACHE IIはICU入室後24時間以内に一度だけ適用され、12の生理学的変数の最悪値、年齢、慢性疾患の有無を用いて院内死亡率を予測します。これは入室時の重症度の「スナップショット」です。一方、SOFAは毎日計算され、時間の経過に伴う臓器機能障害の進行を追跡できます。これは重症患者の「映画」です。さらに、SOFAは敗血症の定義基準（Sepsis-3）ですが、APACHE IIは主に予後スコアです。実際には、両者は補完的です。APACHE IIはベースラインリスクを推定し、SOFAは治療への反応を監視します。
人工呼吸器装着患者にCAM-ICUをどのように適用しますか？
CAM-ICUは人工呼吸器装着患者にも適用可能です。まず、RASS（リッチモンド興奮・鎮静スケール）を評価します。RASSが-4または-5（深昏睡）の場合は中止します。患者はテストを受けることができません。RASSが-3以上の場合は続行します：(1) 精神状態の急性変化または変動 — ベースラインと比較します。(2) 不注意 — 文字テスト（S-A-V-E-A-H-A-A-R-Tのシーケンスで「A」を聞いたら手を握る）または画像テスト。(3) 思考の混乱 — 簡単な質問を4つ行い、指を2本挙げるように依頼します。(4) 意識レベルの変化 — RASSが0以外。特徴1 + 2 +（3または4）が存在する場合、せん妄と診断されます。評価は各勤務帯ごとに行う必要があります。
