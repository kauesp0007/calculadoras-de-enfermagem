# OBJETIVO DA FASE

Após a conclusão da Fase 1, o usuário já consegue autenticar-se utilizando Firebase Authentication através do login Google e login por e-mail/senha.

Entretanto, até este momento o sistema conhece apenas o usuário autenticado pelo Firebase Authentication.

Nesta fase será implementado o Sistema de Perfil do Usuário, responsável por transformar um usuário autenticado em um usuário pertencente ao ecossistema do projeto Calculadoras de Enfermagem.

O objetivo desta fase é criar toda a infraestrutura responsável por armazenar, atualizar, recuperar e disponibilizar as informações do usuário para qualquer página do sistema.

Esta será a base para todas as próximas fases:

- Favoritos
- Histórico
- Área Premium
- Biblioteca Premium
- Cursos
- Certificados
- Assinaturas
- Painel Administrativo

Nenhuma destas funcionalidades deverá ser implementada nesta fase.

Esta fase criará apenas a infraestrutura necessária.

--------------------------------------------------------------------------------------------------------

# OBJETIVOS

Ao término desta fase o sistema deverá ser capaz de:

✓ Detectar automaticamente um novo usuário autenticado.

✓ Verificar se já existe um documento correspondente no Firestore.

✓ Criar automaticamente o documento caso seja o primeiro acesso.

✓ Atualizar automaticamente o último acesso.

✓ Carregar automaticamente todas as informações do usuário.

✓ Disponibilizar essas informações para qualquer página do projeto.

✓ Atualizar automaticamente o menu superior quando existir login.

✓ Exibir foto, nome e informações do usuário.

✓ Implementar página Perfil.

✓ Implementar página Configurações.

✓ Preparar completamente a estrutura para Favoritos, Histórico e Premium.

--------------------------------------------------------------------------------------------------------

# FILOSOFIA DA FASE

O Firebase Authentication NÃO será considerado o banco de dados do usuário.

Ele será utilizado apenas para autenticação.

Todos os dados do usuário pertencentes ao sistema deverão ficar armazenados exclusivamente no Firestore.

Authentication será responsável apenas por:

- autenticar
- recuperar sessão
- recuperar token
- recuperar uid

Todo o restante será responsabilidade do Sistema de Perfil.
