Indicações

  • Injeções IM — Via profunda requer calibre adequado
  • Injeções SC — Via subcutânea com agulha curta
  • Injeções ID (intradérmicas) — Testes diagnósticos
  • Coleta de sangue — Acesso venoso para amostras

Contraindicações

Reutilização de agulha descartável
Reencapar agulhas

Alertas

  • Acidente perfurocortante: Nunca reencapar agulhas. Descarte imediato em coletor perfurocortante.
  • Via errada: Confirme via de administração antes de selecionar agulha.
